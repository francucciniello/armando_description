If you just build the package and run the launch file, the arm won't appear in Gazebo. We should add the right dependencies to the file package.xml, but this is not the goal of the classwork. To see the arm, you have to use the command "rosdep install --from-paths src --ignore-src -y" inside the container. If don't touch the dependencies, this command should be used every time we run the package. If the command doesn't work, use "sudo apt-get update" and repeat the process. After that, you can use the launch files to open Gazebo and Rviz. To control the manipulator, open a second terminal and connect it to the running container, then use the command  "ros2 run armando_description keyboard_teleop". Now, you will see the arm moving both in Gazebo and Rviz. If you open another terminal and connect it to the container, typing "rqt", you will be able to use the "image_view" plugin to see what the camera is looking at.
